The reality hit really deep when I took the first WOD in class about 2 weeks ago. I froze up and did not know what to do. After a few WODs, this order started to read naturally, first the name, then what it is. ES6 features like let and const, arrow functions, and template literals also showed up constantly, and they make the code shorter than the Java equivalent.

*Is TypeScript good software engineering?*

Some people say that catching type errors before run time is a kind of cheat, and that a real programmer should just be careful. I see it differently. Catching mistakes early is the whole point of good engineering. In plain JavaScript, passing a string where a number was expected might not break anything until the program is already running, maybe in front of a user. TypeScript flags it the moment I write it. On a team, where I am reading and changing other people's code, types also act as documentation. I can see what a function expects without digging through it. The tradeoff is a little more typing and a compile step, but I think that is a small price for fewer surprises.

*Athletic software engineering*
*Dealing with DNFs*

There were WODs I did not finish (DNF), and I was hard on myself about it. Instead of staying frustrated, I reflected on what happened and what I could do better, and I kept practicing. Repeating the same WOD after watching the solution helped, the second attempt always felt less like guessing and more like following steps I understood.

*Pressure is part of the job*

The WODs are stressful, but when I look at the bigger picture, professional software engineers probably feel the same pressure with deadlines, bugs in production, and code reviews. It also reminds me of my time in the United States Marine Corps. The atmosphere was similar, there was little room for mistakes, and when they happened, you were held accountable. The way we got better there was the same way WODs are designed to work, repetition until the task becomes second nature.

*Will this style of learning work for me?*

I think it will, as long as I treat it seriously. This education costs money, but more importantly it costs my time, and I don't want to waste either one. Going forward, I plan to do each practice WOD more than once, time myself at home, and review ES6 syntax before class so I'm not seeing it for the first time under the clock. Freezing up on that first WOD was uncomfortable, but it showed me exactly what I need to work on, and that is what I needed.
